# Pay365 — HR & Payroll Operations Platform

An integrated human resource and payroll management platform featuring employee master data, contracts, working schedules, attendance tracking, leave allocation and request workflows, configurable salary structures and rules, in-process pure TypeScript payroll calculation engine, and live reporting.

## Design System & Typography

- **Typography**: `Bricolage Grotesque`, sans-serif (used for both display headings and body interface text across the entire application).
