# TASK-017 — Payslip PDF Generation (`pdfkit`) — Detailed Plan

**Priority:** P1 · **Deps:** TASK-015 (payslips persisted) · **Contract:** `04-API-CONTRACTS.md` §payruns & payslips, `08-ROADMAP-AND-TASKS.md` TASK-017

## Goal

Printable payslip PDF documents, rendered from **persisted** `payslip_lines` data only
(**zero recalculation** — the engine contract's history/snapshot principle), streamed
by two endpoints with strict access control.

## Acceptance Criteria (from the roadmap)

1. PDF renders: employee identity, company header, rule line table, **net salary in words**
2. Non-owner employees cannot access other users' PDFs (**403**)

## Endpoints (2)

| # | Endpoint                     | Role                | Ownership rule                     |
|---|------------------------------|---------------------|------------------------------------|
| 1 | `GET /payslips/:id/pdf`      | HR_PAYROLL_USER+    | none (back-office)                 |
| 2 | `GET /me/payslips/:id/pdf`   | any authenticated   | `payslip.employeeId === session.employee_id`, else **403** |

Response headers for both:

```
Content-Type: application/pdf
Content-Disposition: inline; filename="payslip-<employee_code>-<period_start>.pdf"
```

The AC mandates 403 for non-owner PDFs — stricter than TASK-015's 404 on `/me/payslips/:id`
detail (which hides existence). The PDF is a document leak surface, so the explicit 403
from the AC wins; documented as intentional.

## Files (2 new, 3 modified, 1 dependency added)

### 1. NEW `payroll-run/number-to-words.js` (pure, ~45 lines)

Indian numbering system for "net salary in words":

```
crore   = floor(n / 10^7)   → One Crore
lakh    = floor(rest / 10^5)
thousand= floor(rest / 10^3)
hundred = floor(rest / 10^2)
last two digits via static tens/ones tables (0-99)
```

Public API:

```js
export function numberToIndianWords(amount)  // Decimal/number -> "Fifty Five Thousand Rupees Only"
// rules:
//   0              -> "Zero Rupees Only"
//   paise > 0      -> "... Rupees and Fifty Paise Only"
//   negative       -> "Minus " prefix (defensive; nets should never be negative)
//   words in Title Case, joined with single spaces
```

Exact expected outputs (these become unit tests):

| input      | output                                                     |
|------------|------------------------------------------------------------|
| 0          | `Zero Rupees Only`                                          |
| 99         | `Ninety Nine Rupees Only`                                   |
| 100        | `One Hundred Rupees Only`                                   |
| 55000      | `Fifty Five Thousand Rupees Only`                           |
| 126000     | `One Lakh Twenty Six Thousand Rupees Only`                  |
| 12345678.5 | `One Crore Twenty Three Lakh Forty Five Thousand Six Hundred Seventy Eight Rupees and Fifty Paise Only` |

### 2. NEW `payroll-run/payslip-pdf.service.js` (~90 lines)

```js
import PDFDocument from 'pdfkit';

export async function renderPayslipPdf(payslip) {
  // payslip = the ALREADY-FETCHED public shape from payslip.service (with lines)
  // returns Buffer — collected on the pdfkit doc's 'end' event
}
```

Why Buffer, not a live stream: simpler error handling, and TASK-018 (bulk email)
needs `nodemailer` attachments as Buffers anyway. Demo scale makes the memory
cost negligible (single-page A4 ≈ 5-15 KB).

Layout (all coordinates via pdfkit `doc.text(..., x, y)` — no template engine):

```
A4 (595 x 842 pt), 50pt margins
────────────────────────────────────────────────────────
 y= 50  Pay365 — HR & Payroll          (16pt bold, left)
 y= 50  Payslip                        (16pt bold, right)
 y= 78  Employee:  Rahul Verma (DEMO-EMP-001)
 y= 94  Period:    2026-09-01 → 2026-09-30
 y=110  Payrun:    September 2026 — Standard (COMPUTED)
 y=140  ── table header (10pt bold, grey background) ──
        Code | Name | Category | Amount        (4 columns, x = 50/170/400/490)
 y=158+ one row per persisted payslip_line, ordered by sequence (10pt)
        deduction rows print the negative amount as stored
 y=~    ── totals block ──
        Gross:      63,000.00        (10pt)
        Deductions:  8,000.00
        NET:        55,000.00        (12pt bold, rule above)
 y=~    In words: Fifty Five Thousand Rupees Only   (10pt italic)
 y=~    footer: Generated by Pay365 on <ISO timestamp>  (8pt grey, y=792)
────────────────────────────────────────────────────────
```

- Money formatting: `Intl.NumberFormat('en-IN', { minimumFractionDigits: 2 })`
  (frontend uses the same locale per `06-FRONTEND-ARCHITECTURE.md`)
- amounts come straight from the persisted lines — no engine call (AC: zero recalculation)
- single page guaranteed for sane line counts (7-20 lines typical)

## Data flow (zero recalculation chain)

```
payslip_lines table  (persisted at COMPUTE time)
        ↓  prisma findUnique (existing detail include)
payslip.service.getPayslip / getOwnedPayslip
        ↓  public shape, lines already sequence-ordered
renderPayslipPdf()   — pure pdfkit drawing, no Prisma, no engine
        ↓
Buffer -> res.send()
```

## Error mapping

| Case                       | Status | Code         |
|----------------------------|--------|--------------|
| malformed uuid param       | 404    | NOT_FOUND    |
| payslip does not exist     | 404    | NOT_FOUND    |
| non-owner (self endpoint)  | 403    | FORBIDDEN    |
| EMPLOYEE hits back-office  | 403    | FORBIDDEN    |
| pdfkit failure             | 500    | INTERNAL     |
